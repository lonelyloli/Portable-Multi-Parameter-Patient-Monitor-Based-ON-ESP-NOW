This study presents a portable, multi-parameter patient monitor built on a dual/multi-node ESP32 architecture communicating via ESP-NOW, integrating four sub-modules: three-lead ECG with lead-selection and lead-fail detection, NIBP measurement with spreadsheet-based logging, SpO₂ and skin-temperature sensing with a BMS, and HR/RR extraction with an alarm system. Each node performs analog signal conditioning (instrumentation amplifiers, HPF/LPF, notch filters, demultiplexers) and digital processing (Pan–Tompkins QRS detection, ECG-derived respiration, oscillometric NIBP, ratio-of-ratios SpO₂), with results displayed on a Nextion touchscreen and visualized via Visual Basic. Validation against clinical simulators and reference monitors showed all parameters within clinical tolerance: HR error 0–0.66%, RR error <0.9%, NIBP error ≈±1–2%, SpO₂ error 0.6% (2.9% vs. simulator), and skin-temperature error 0.6%, with reliable ESP-NOW range up to 15–20 m indoors. The system demonstrates that a low-cost, ESP32/ESP-NOW-based architecture can achieve clinically acceptable multi-parameter monitoring with integrated safety features, making it a viable reference design for resource-limited settings.
